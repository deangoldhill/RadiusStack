API Documentation & Tester

Live route inventory: registered endpoints. Click an endpoint to stage it in the tester. Write operations are marked and are never sent until you press Send request.

Paging: Users, MAC Auth, Active Sessions, Accounting, Audit Log, and Auth Logs support ?page=1&page_size=25, with page sizes 25, 50, or 100. Paged responses contain items, total, page, pageSize, and totalPages. Tenant context: a selected tenant shows tenant-specific routes and requests automatically carry X-Tenant-ID; Global shows platform management and operational routes. Operational routes appear in both contexts. RadSec trust model: the per-tenant client certificate CA signs/verifies NAS client certificates; it does not sign the shared listener. Selected authorized tenants with RadSec enabled and provisioned download GET /api/tenant-radsec/download/server-trust-ca as the shared RadSec server trust CA that NAS clients must trust. /server is only the optional public server leaf, never a trust CA. UniFi RadSec: In UniFi, upload only the shared RadSec server trust CA in the CA field because it issued the listener certificate; upload the generated client full-chain PEM and encrypted key in the separate client fields. Do not combine the shared server trust CA and tenant client CA. RadSec client delivery: POST /api/nas/{id}/radsec/client requires {"format":"p12"} or {"format":"pem"}; downloads are separate, authenticated, one-time tokens valid for 10 minutes. NAS client credentials are generated first: P12 has one explicit Download P12 bundle action; PEM exposes separate Download client certificate (.pem) and Download encrypted private key (.key) actions, each consuming its own token only when clicked. PEM private keys are encrypted and the returned password is shown only at generation. Global-only routes (platform, certificates, HA, backups, Radius server counters, and tenant management) remain visible only in Global. Multi-tenancy bootstrap: GET /api/auth/context; tenant management samples are under the Multi-Tenancy group. Replace all {placeholder} path values before sending.
