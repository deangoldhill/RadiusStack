API Documentation & Tester

Live route inventory: registered endpoints. Click an endpoint to stage it in the tester. Write operations are marked and are never sent until you press Send request.

Paging: Users, MAC Auth, Active Sessions, Accounting, Audit Log, and Auth Logs support ?page=1&page_size=25, with page sizes 25, 50, or 100. Paged responses contain items, total, page, pageSize, and totalPages. Tenant context: in a selected tenant the catalogue shows only tenant-aware routes and requests automatically carry X-Tenant-ID. Global-only routes (platform, certificates, HA, backups, Radius server counters, and tenant management) remain visible only in Global. Multi-tenancy bootstrap: GET /api/auth/context; tenant management samples are under the Multi-Tenancy group. Replace all {placeholder} path values before sending.
