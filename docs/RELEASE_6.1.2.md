# RadiusStack 6.1.2

Changes since the verified 6.1.1 source archive:

- **MAC-auth manufacturer names.** A bundled Wireshark MAC allocation registry provides offline lookups for manual, bulk, and auto-created MAC devices. The locally resolved vendor is stored with each device; a bounded background worker fills existing devices. Device details show the vendor in brackets beside the MAC address, or `(Unknown Device Vendor)` when there is no match. Detail views do not make a vendor-network request. The in-memory registry attempts a bounded weekly refresh; the bundled snapshot remains available if refresh fails. Randomized/locally administered MACs are not assigned a guessed manufacturer.
- **Per-tenant display preference.** The MAC Authentication widget has an enabled-by-default **Show MAC Auth Device vendor names** checkbox. Its per-tenant value is scoped to the selected tenant, and disabling it hides the vendor from that tenant's device details. Existing installs receive an additive `mac_auth_devices.vendor_name` migration; new installs receive the column in the initialization schema. No existing device, tenant, profile, or plan data is removed.
- **Settings polish.** The RadSec widget matches the standard neutral card colour. RadSec, Notifications, and Reply Attribute Catalogue have icons, and RadSec/Notifications collapse arrows sit on the right. TOTP enrolment-code expiry moved from its one-field widget into General Settings in the Global context, retaining its existing global setting.
- **Profile role label.** The Profile modal now shows **My permissions** below the version: `Platform administrator` for a full platform administrator, `Multi-tenant administrator` for an administrator assigned to multiple tenants, or `Tenant administrator` for one tenant. The label is derived from authenticated account/context data, not the tenant currently selected in the menu.
